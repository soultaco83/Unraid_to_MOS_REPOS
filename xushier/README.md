# xushier - MOS Templates

Docker container templates from [xushier/Unraid-Docker-Templates](https://github.com/xushier/Unraid-Docker-Templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **xushier**
* Source: https://github.com/xushier/Unraid-Docker-Templates
* Templates: **70**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
