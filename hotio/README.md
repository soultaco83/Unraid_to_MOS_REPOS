# hotio - MOS Templates

Docker container templates from [hotio/unraid-templates](https://github.com/hotio/unraid-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **hotio**
* Source: https://github.com/hotio/unraid-templates
* Templates: **27**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
