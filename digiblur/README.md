# digiblur - MOS Templates

Docker container templates from [digiblur/unraid-docker-templates](https://github.com/digiblur/unraid-docker-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **digiblur**
* Source: https://github.com/digiblur/unraid-docker-templates
* Templates: **25**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
