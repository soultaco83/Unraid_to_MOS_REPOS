# Lime Technology - MOS Templates

Docker container templates from [unraid/docker-templates](https://github.com/unraid/docker-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **Lime Technology**
* Source: https://github.com/unraid/docker-templates
* Templates: **1**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
