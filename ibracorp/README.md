# IBRACORP - MOS Templates

Docker container templates from [ibracorp/unraid-templates](https://github.com/ibracorp/unraid-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **IBRACORP**
* Source: https://github.com/ibracorp/unraid-templates
* Templates: **55**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
