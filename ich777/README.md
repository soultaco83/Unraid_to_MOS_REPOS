# ich777 - MOS Templates

Docker container templates from [ich777/docker-templates](https://github.com/ich777/docker-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **ich777**
* Source: https://github.com/ich777/docker-templates
* Templates: **146**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
