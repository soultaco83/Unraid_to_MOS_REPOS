# devzwf - MOS Templates

Docker container templates from [devzwf/unraid-docker-templates](https://github.com/devzwf/unraid-docker-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **devzwf**
* Source: https://github.com/devzwf/unraid-docker-templates
* Templates: **47**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
