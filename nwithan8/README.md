# nwithan8 - MOS Templates

Docker container templates from [nwithan8/unraid_templates](https://github.com/nwithan8/unraid_templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **nwithan8**
* Source: https://github.com/nwithan8/unraid_templates
* Templates: **544**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
