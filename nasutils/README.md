# NasUtils - MOS Templates

Docker container templates from [NasUtils/unraid-docker-templates](https://github.com/NasUtils/unraid-docker-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **NasUtils**
* Source: https://github.com/NasUtils/unraid-docker-templates
* Templates: **8**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
