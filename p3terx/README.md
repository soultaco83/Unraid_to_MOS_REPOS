# P3TERX - MOS Templates

Docker container templates from [P3TERX/unraid-docker-templates](https://github.com/P3TERX/unraid-docker-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **P3TERX**
* Source: https://github.com/P3TERX/unraid-docker-templates
* Templates: **2**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
