# binhex - MOS Templates

Docker container templates from [binhex/docker-templates](https://github.com/binhex/docker-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **binhex**
* Source: https://github.com/binhex/docker-templates
* Templates: **65**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
