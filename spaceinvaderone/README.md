# SpaceinvaderOne - MOS Templates

Docker container templates from [SpaceinvaderOne/Docker-Templates-Unraid](https://github.com/SpaceinvaderOne/Docker-Templates-Unraid), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **SpaceinvaderOne**
* Source: https://github.com/SpaceinvaderOne/Docker-Templates-Unraid
* Templates: **25**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
