# Eurotimmy - MOS Templates

Docker container templates from [Eurotimmy/unraid-templates](https://github.com/Eurotimmy/unraid-templates), converted to the
[MOS Hub](https://github.com/ich777/mos-templates) JSON template format.

* Maintainer: **Eurotimmy**
* Source: https://github.com/Eurotimmy/unraid-templates
* Templates: **8**

## Layout

```
maintainer.json
docker/<App>.json
images/            (icons that were hosted in the source repo)
```

Generated with `tools/convert_sources.py` (Docker templates only, plugins excluded).
